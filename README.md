# Encuesta: ¿Tiene sentido una impresora 3D ahora?

Web estática lista para Vercel.

## Archivos
- index.html
- style.css
- script.js

## Publicar en Vercel
1. Crea un repositorio en GitHub.
2. Sube estos tres archivos a la raíz.
3. En Vercel, importa el repositorio.
4. Framework Preset: Other.
5. No necesitas build command.
6. Deploy.

También puedes arrastrar la carpeta a Vercel si utilizas su opción de despliegue compatible.

## Qué hace
- Presenta brevemente la propuesta.
- Hace 5 preguntas de Sí/No.
- Si se responde No, obliga a escribir el motivo.
- Permite volver atrás.
- Genera un resumen final.
- Guarda una copia local en el navegador mediante localStorage.
- Permite imprimir el resultado.

Nota: esta versión NO envía las respuestas a internet. Cada navegador guarda sus propias respuestas.
